## 🎯 TOPIC 01: Forming Questions Like a Tech Pro

### Part A: Direct Questions (The Inversion Rule)
$$\mathbf{Wh\text{-}Word} + \mathbf{Auxiliary\ (do / does / did / can / will / is / are)} + \mathbf{Subject} + \mathbf{Base\ Verb} \dots?$$

* In present simple tense with regular verbs (*return, work, fail*):
  * Singular subject (the API, the server): use **`does + base verb`**
  * Plural subject / you / they: use **`do + base verb`**
  * Past tense: use **`did + base verb`**

---

### Part B: Indirect Questions (The Polite Embedded Rule)
$$\text{Polite Intro\ (Could you tell me... / Do you know... / I'm wondering...)} + \mathbf{Wh\text{-}Word\ /\ IF} + \mathbf{Subject} + \mathbf{Verb} \dots$$

* Inside an indirect question, **never use auxiliary `do / does / did`**, and **do not invert** the verb. Use normal affirmative word order!

## 🏋️‍♂️ The 6 Practice Sentences: Corrections & IPA Key

### 1. Finding Figma Files
* ❌ *Where I can find the Figma design file?*
* ✅ **"Where can I find the Figma design file?"**
* 🔤 **IPA:** `/wer kæn aɪ faɪnd ðə ˈfɪɡ.mə dɪˈzaɪn faɪl?/`

---

### 2. Investigating an API Error
* ❌ *Why the API returns a 404 error?*
* ✅ **"Why does the API return a 404 error?"**
* 💡 *Explanation:* In present simple direct questions, you must add auxiliary **`does`** before the subject, and change `returns` back to the base verb `return`.
* 🔤 **IPA:** `/waɪ dʌz ði ˌeɪ.piːˈaɪ rɪˈtɝːn ə fɔːr oʊ fɔːr ˈer.ɚ?/`

---

### 3. Sprint Planning & Time Estimation
* ❌ *How much time we will spend on this sprint?*
* ✅ **"How much time will we spend on this sprint?"**
* 🔤 **IPA:** `/haʊ mʌtʃ taɪm wɪl wiː spend ɑːn ðɪs sprɪnt?/`

---

### 4. Code Review / Asking About an Algorithm
* ❌ *Could you please explain how does this algorithm work?*
* ✅ **"Could you please explain how this algorithm works?"**
* 💡 *Explanation:* In indirect questions, remove `does` and add the singular `s` to the verb `works`.
* 🔤 **IPA:** `/kʊd juː pliːz ɪkˈspleɪn haʊ ðɪs ˈæl.ɡə.rɪ.ðəm wɝːks?/`

---

### 5. Testing Readiness
* ❌ *I am wondering is this feature ready for testing?*
* ✅ **"I'm wondering if this feature is ready for testing."**
* 💡 *Explanation:* Use **`if`** or **`whether`** to link the clause, and move `is` after the subject (`this feature is ready`).
* 🔤 **IPA:** `/aɪm ˈwʌn.dɚ.ɪŋ ɪf ðɪs ˈfiː.tʃɚ ɪz ˈred.i fɚ ˈtes.tɪŋ./`

---

### 6. Outage Root-Cause Investigation
* ❌ *Do you know what is the root cause of this outage?*
* ✅ **Option A (With 'what'): "Do you know what the root cause of this outage is?"**
* ✅ **Option B (Simplified): "Do you know the root cause of this outage?"**
* 💡 *Explanation:* In Option A, `is` moves to the very end of the clause. Option B is also completely natural!
* 🔤 **IPA (Option A):** `/duː juː noʊ wɑːt ðə ruːt kɑːz əv ðɪs ˈaʊ.t̬ɪdʒ ɪz?/`
* 🔤 **IPA (Option B):** `/duː juː noʊ ðə ruːt kɑːz əv ðɪs ˈaʊ.t̬ɪdʒ?/`
