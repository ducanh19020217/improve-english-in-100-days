**Topic:** Clarifying Jira Requirements & Acceptance Criteria  
**Date:** 2026-11-18

## 🎯 Today's Scenario

You are reviewing a Jira ticket before starting work. The requirement says:

> “As a user, I want to reset my password so that I can regain access to my account.”

The ticket does not explain how long the reset link remains valid, what happens after it expires, or whether the user should receive a confirmation email. Write a short message to your product owner asking for clarification. Try to ask about the missing details politely and clearly.

**Your turn:** Write 3–5 sentences in English. Include:
1. The detail you need clarified.
2. A question about the expired link.
3. A question about the confirmation email.

Don't worry about mistakes. I'll review your answer, explain the key corrections, and help you make it sound natural in a Jira or Slack discussion.

## 📚 Today's 10 Words & Phrases

Learn these as useful chunks. Read each example aloud, then try using at least three in your reply.

1. **review a requirement** — xem xét yêu cầu  
   *I’ve reviewed the password reset requirement.*
2. **clarify a requirement** — làm rõ yêu cầu  
   *Could you clarify one detail for me?*
3. **password reset flow** — quy trình đặt lại mật khẩu  
   *I have a question about the password reset flow.*
4. **reset link** — đường dẫn đặt lại mật khẩu  
   *Should we send users a reset link?*
5. **one-time password (OTP)** — mật khẩu dùng một lần  
   *Should users enter a one-time password?*
6. **be valid for 60 minutes** — có hiệu lực trong 60 phút  
   *Should the reset link be valid for 60 minutes?*
7. **expire** — hết hạn  
   *What should happen when the link expires?*
8. **confirmation email** — email xác nhận  
   *Should we send a confirmation email after the reset?*
9. **before I start implementation** — trước khi tôi bắt đầu triển khai  
   *I’d like to confirm this before I start implementation.*
10. **test it in staging** — kiểm thử trên môi trường staging  
    *I’ll test the password reset flow in staging.*

### Read Aloud

Read this short message aloud twice. On the second read, try to say it smoothly in meaningful chunks:

> “I’ve reviewed the password reset requirement. Before I start implementation, could you clarify the flow? Should users receive an OTP or a reset link? How long should it be valid, and should we send a confirmation email?”

### Natural Conversation Practice

Imagine the product owner replies: **“Let’s use a reset link. It should expire after 30 minutes.”** Respond naturally with one follow-up question—for example, ask what should happen when the link expires. Use your own words; you can mix in Vietnamese if you get stuck.

## 🧰 Useful Phrases (Use these if you need them)

- **Could you clarify...?** — Bạn có thể làm rõ... không?
- **What should happen if...?** — Điều gì nên xảy ra nếu...?
- **Should we also...?** — Chúng ta có nên... nữa không?
- **Before I start implementation, ...** — Trước khi tôi bắt đầu triển khai, ...
- **I want to make sure I understand the requirement correctly.** — Tôi muốn chắc rằng mình hiểu đúng yêu cầu.

> “Before I start implementation, could you clarify how the password reset flow should work?”
